MEDIA PRESENTASI INTERAKTIF — DIGITALISASI PEMBELAJARAN

Cara menjalankan:
1. Ekstrak seluruh isi ZIP ke satu folder.
2. Klik dua kali index.html. Media langsung terbuka di browser tanpa login dan tanpa server.
3. Gunakan tombol Berikutnya/Sebelumnya, titik navigasi, atau tombol panah kiri/kanan pada keyboard.
4. Tombol ☷ menampilkan daftar bagian; tombol ⛶ membuka layar penuh jika browser mengizinkan.

Isi presentasi:
- Pembuka dan 8 bagian materi sesuai tabel yang diberikan.
- Pilihan fasilitas sekolah, perbandingan contoh kelas, tab aktivitas, kuis, dan permainan mencocokkan.
- Bagian langkah memulai menampilkan pilihan Canva dan HTML; penutup hanya "Terima kasih".

Cara memasang background sendiri:
1. Masukkan gambar ke folder assets/background dalam ZIP yang sudah diekstrak.
2. Beri nama background.png, background.jpg, background.jpeg, atau background.webp.
3. Muat ulang index.html. Background akan tampil di semua bagian dengan lapisan terang agar teks mudah dibaca.
4. Jika tidak ada gambar, media tetap menampilkan latar warna bawaan.

Untuk GitHub Pages, unggah index.html, style.css, dan script.js di root repositori.
Tidak ada dependensi, akun, atau permintaan data ke layanan luar.
